# Fraternity House Points Tracker

A java application designed to help fraternity members track activities, earn points, and compete on a house leaderboard.

## The Problem

Tracking fraternity house points manually can become confusing and disorganize. It can be difficult to keep track of everyone's points. This project aims to make the process easier by providing one system to record all this information.

## How It Works

The application will allow fraternity members to;

- Keep track of member information.
- Record completed activities.
- View individual point totals.
- See a leaderboard showing members rankings
  
The first version will focus on the basic features needed to track activities and points.
